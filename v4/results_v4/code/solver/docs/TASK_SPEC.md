# 正式执行任务书 V3

## 0. 目标与解释边界

本轮不做粒径反演，而是为已知直径 30、100、200 nm 的 Fe₃O₄ 单球生成三维轴向成像响应。每次场景仅一个球，三种直径分别计算，永不叠加。

玻璃—水界面为全局 Z=0；球心高度 `zp=D/2`。`zeta` 对应论文式(7)中的相对焦点扫描变量，零点按输入几何约定固定。变化的是焦点/台位置对应的光程，不是球相对界面的高度。

“以球心为中心上下各半景深”的操作解释为对称扫描窗口。±170 nm 来自此前约定的名义尺度，**不是经高NA理论或实测确定的真实景深**。不得改称“完整电磁场范围”。界面以下的负局部扫描位置只是焦点参数，不能用 `zeta<-R` 为理由裁掉切片。

主数据 `C(zeta,y,x)` 是成像观察面的 through-focus 数据体，不是样品空间 `E(X,Y,Z)`。粒子是球，干涉分布不必是球；不得通过旋转二维图、镜像、裁剪球壳或复制切片生成三维数据。

## 2. 计算网格和工作量

目标配置：`configs/target_Fe3O4_NA145.json`。

- zeta：-170 到 +170 nm，步长2 nm，共171层，含0。
- x,y：-1200 到 +1200 nm，步长10 nm，各241点，物方等效数值坐标。
- 目标三组：各 `(171,241,241)`，每组9,931,851点，合计29,795,553点。
- 横向网格不是相机像元，z步长不是轴向分辨率。
- 初始正式角积分点数：临界以下512，以上256；分界 `u=ns`，上限 `u=NA`。不足则加密，不能改上限。
- 径向积分网格1601点，必须覆盖正方形视场对角线，不能只覆盖横轴端点。
- CPU complex128/float64计算；HDF5默认float32存储，需量化误差检查。
- 主要数组未压缩约2.09 GB（十进制，3组；未计少量元数据）。运行器检查估算量×1.5加256 MiB余量，压缩后尺寸依结果变化，不能预先承诺。

Pilot保持同样轴向窗口，步长10 nm、35层；横向±600 nm、20 nm步长、61点。Pilot不是主结果，也不是对最终数据的插值来源。

另做低成本长程诊断：zeta=-3000:10:3000 nm，保存轴上曲线和x-zeta剖面即可。它用于查看局部窗口与完整轴向结构的关系，不替代指定主网格，不据此擅自改变用户窗口。

## 5. 阶段S2：公式与偏振链审计

参见 FORMULA_AUDIT，不得跳过以下事项：

1. 定义入射方向、返回收集方向、Mie散射角、物镜角、像方角、方位角和所有基矢。写出Mie基到返回光p/s基的变换，而不只画箭头。
2. 独立实现/推导 S1→S3→S6 的Jones矩阵链。比较文中线偏振陈述与补充Ei=(0,1)，明确坐标整体旋转是否等价。
3. `mu=-kzs/ns` 表示正入射后的后向方向；此时不能无说明地把标准Mie S2直接代入另一套p基的公式。当前候选 `S2_return=-S2_Mie` 仅是已显式标注的基变换修补；必须以整个链的独立计算核查，禁止为贴近旧图而选符号。
4. S12/S13 中 `Ex` 的J2项符号以直接方位角积分校验。原版与补充不同，旧标量强度可能因双方同时改号而不变，这不代表复矢量场正确。
5. 文本S4/S5的角函数疑似重复，不盲抄。用标准Mie解析定义、独立实现及版本原件核对；保留校勘说明，不把预印本排版疑点称成已确认作者错误。
6. Fresnel系数必须和入射/返回p/s基同约定。验证法向、无反差、能流守恒（适用时）、临界点两侧连续极限；p偏振不是只检查法向一个点。
7. RW积分的积分变量变换、Jacobian、apodization、M=170、物方/像方x,y对应关系和S11近轴像方近似逐项核验。避免多乘M或少乘M²。
8. 油层厚度随zeta按(7)更新；参考/散射OPD按(9)(10)分别计算，不额外再乘一个相同离焦相位。
9. 保留两横向像面分量Ex,Ey。不要无依据把它们宣称为样品空间完整Ex,Ey,Ez。

审计输出每项必须给出：原文位置→数学式→坐标约定→代码函数→独立测试→状态。不能只有“已检查”一句话。

## 6. 阶段S3：高NA与相对振幅

### 高NA

目标1.45>水折射率1.33；原论文计算1.35也略大于1.33。因此，NA改回1.35不能自动消除超临界处理问题。

当前候选对u>ns使用复kz和Mie角函数解析延拓，这不是严格球—基底多次相互作用解。必须保持被动支 `Im(kzs)>=0`，检查高度衰减及临界点加密。输出临界以下/以上的复场贡献，并比较合场，不把“瞳面面积占比”当成“信号占比”。不得把上限暗中裁成ns。

应优先用与论文近似一致的偶极角谱/分层Green函数作小粒径极限核验。完整T矩阵/有限元是可选独立基准：若使用，明确其粒子—基底多次反馈与论文近似的差异，不能看到不一致就硬改主模型。不得把完整Maxwell工具缺失变成无限扩展课题的理由；未核实则保留未核实标记。

### 相对复振幅

论文的Cs包含收集效率η，并不等于证明Cs/Cr=η。默认γ=.5是演示幅相规范，不是测量值。严格区分未知幅度和未知相位。

输出 `Er, Es_unit`，以及 `U=|Es_unit|²`、`Q=Er*·Es_unit` 的实虚部。对任意复γ：

`I_total=I_ref+|γ|²U+2 Re(γ Q)`。

这是保存缺失标定信息的可追溯表示，不是从真实Fe₃O₄颗粒直接获得绝对对比度。若独立推导能固定γ，必须证明入射场、Fresnel、Mie量纲、光瞳和探测偏振完整一致，不能靠最小二乘调γ去拟合想要的形状。

可做敏感性报告 γ∈{0.25,0.5,1.0}，另取固定模的几个相位；统一用于三粒径，只作为诊断，不挑选最漂亮结果。

## 7. 阶段S4：数值验证与控制组

```bash
python tools/numerical_audit.py --out results/numerical_audit.json

python tools/long_profile.py --config configs/target_Fe3O4_NA145.json --output results/target_long
```

必须查看同一坐标下复场，而非单独归一化强度后比较。角积分连续两次加密均检验L2和L∞相对误差；包含离轴与临界附近，不只检查轴上三个点。误差未达 `1e-3`，增加积分密度/采用临界变量变换，最多到预算上限并报告失败，不能删难点或放宽阈值。

补充检查：正式512/256再与1024/512对比；实际1601径向点再与3201点对比；横向10 nm采样与5 nm直接求值的中点比较；2 nm轴向与1 nm直接求值中点比较；Mie截断阶数提高后复振幅变化。所有阈值是本任务数值容差，不是论文给出的误差保证。

论文对照的图形数字化仅作为有限精度比较；标注数字化误差，不能声称访问到作者原始数据或给虚构RMSE。图形相似不替代公式检查。
