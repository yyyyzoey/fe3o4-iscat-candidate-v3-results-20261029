# 现有结果复审：以本轮实际目的为准

## 结论

现有v1.0.0的三种粒径、表面附着几何、NA=1.45、171层及241×241网格符合已约定的数据生成任务。不能说“没有得到三维数据”。但现有默认图件仅包括一种固定参考归一化信号的3张xy切片、xz/yz剖面和一组轴向曲线；尚不足以作为清晰、直观、与模型假设对应的最终图件交付。

本轮应：保留数据 → 做有限的论文公式约定核查 → 明确归一化与相对场幅约定 → 导出完整图件与三维展示。若核查不改公式，不重算光场；若改公式，三种粒径统一重算，旧结果保留。

## 收回不适合本轮的额外门槛

1. 不要求真实实验的激光功率、相机增益或绝对对比度标定。
2. 不要求实现论文之外的球—基底反复散射全波解。
3. 不把噪声、粒子追踪、粒径反演、磁驱动或布朗运动加入本轮。
4. 原双线性插值检查失败继续留档，但它不是已直接计算网格点错误的证明，也不自动要求整个数据体加密。

## 必须保留的最小核验

1. 标准Mie角和返回光局部p/s基与论文记号之间的映射。
2. 同一传播约定中的相位、吸收号和复平方根分支；不能人为移动焦点到峰值。
3. 用同一个正实相对幅度约定处理三种粒径；不能分别调参获得想要的大小排序。
4. 用保存的复场重算强度，并保证图像、CSV、3D网格全部源于同一套HDF5。

## 关于gamma=0.5的纠正

作者补充式S6后的文字给出 eta=asin(min(NA/ns,1))/pi。本轮NA=1.45、ns=1.33时，eta=0.5。
因此“0.5完全没有论文联系”并不准确。但原文说Cs包括eta，并没有单凭该句完整确定Cs/Cr=eta。对于本轮归一化展示，可显式采用CR=1、CS=eta的共同模型幅度约定，不称为实验标定。

对固定相位、正实gamma，J=2 Re(Er*·Es)随gamma线性变化，J/max|J|不受gamma的数值影响；因此归一化干涉形态不需要先做实验标定。该结论不适用于任意复gamma，也不适用于含|Es|²的总强度。

## 关于“像论文一样”

论文图3展示了归一化图，不是要求所有材料、粒径和NA下都出现相同花纹。Fe₃O₄与聚合物材料、NA=1.45与论文计算NA=1.35之间的差别会改变计算结果。本轮应复现方法和图件表达方式，不人工修改数据去匹配论文纹理。
