# V4 完整执行方案：论文近似模型下的三粒径无噪声三维干涉响应

## 0. 唯一任务及验收口径

目标：用论文的Mie散射—Fresnel界面—矢量Richards–Wolf成像—Gibson–Lanni光程差框架，计算30/100/200 nm Fe₃O₄单球。粒子贴附玻璃，固定球心；以各自球心为焦点扫描零点，在名义景深窗口内密切片，保存三维复场与强度，并给出清楚的分层、剖面、曲线及三维图。

本轮复现的是**成像模型的前向仿真**，不包含实验拟合或绝对标定；不做噪声、相机、追踪、反演、悬浮高度扫描、磁驱动、布朗运动、多粒子、真实近场或完整球—基底多次散射。禁止因为缺少这些内容而无限延长本轮。

“球体”仅描述粒子几何。数据体为F(x,y,zeta)，zeta是through-focus扫描参数，不是样品空间近场z坐标。不得把粒子球面画成干涉等值面；不得通过旋转二维剖面制造三维场。

## 4. 有限而必须完成的公式约定核验

### 4.1 Mie及偏振基

所有尺寸用同一完整Mie实现，x=2pi ns a/lambda0。避免把200 nm粒子用Rayleigh体积律替代。
定义并写清：入射方向、收集方向、Mie散射角、局部e_theta/e_phi、返回p/s基、实验室x/y基、时间约定及Fresnel振幅方向。

当前代码使用mu=-kz_s/ns及-S2_Mie tp+S1_Mie ts；附件S6/S13印刷为S2 tp+S1 ts。
不能只看加减号决定谁对谁错。必须提供一页“论文符号→标准Mie符号→代码变量”映射及一次直接矩阵计算。
可能等价的基映射须从几何推导，不能仅定义S2_paper=-S2_code后宣称验证。
最低测试：法向返回光；非零角度；不少于两个非轴对称方位；纯电偶极后向响应；S7二维直接角积分对S11–S13降维积分。
不要求重建实验仪器；也不声称只做单一后向极限就完成全链验证。
如未能消除歧义，保留两个实现的差异及标签，至少交付现有候选图；但不能宣布“严格公式复现通过”。

### 4.2 相位与高NA

使用u=ni sin(theta)，积分上限NA；不得把1.45暗改为1.33。
kz_j=k0 sqrt(n_j²-u²)，采取与时间/传播方向一致、向对应传播方向衰减的分支。对于向+z传播的exp(+ikz z)，要求Im(kz)>=0。
在u=ns处拆分积分并检查左右极限；复角解析延拓属于本轮近似模型说明，不能伪装成完整球—界面近场求解。

本轮验收要求：复平方根分支、相位与积分在该近似模型内部一致且收敛；不要求新增FDTD/BEM/T-matrix全波认证。
保存一份临界内/外扇区贡献诊断；分析振幅与相位，不能只检查程序无NaN。

### 4.3 参考/散射相对幅度

补充S6之后写eta=asin(min(NA/ns,1))/pi，本轮eta=0.5。
采取一个公开、统一的无量纲模型约定CR=1、CS=eta；保留论文显式i因子和传播相位。
如果CS包含其他已明确的共同因子，按完整定义保存；禁止隐式重复乘收集效率。代码的unit散射场若已设CS/CR=1，则只在合成时乘一次gamma=eta。
**这个约定不是原文唯一确定的绝对幅度，也不是实验标定。**
不为三个粒径分别调gamma；不为“更清晰”人为改变相位。检查S4/S5中的相位因子如何进入后续场，不能在CS定义与Mie函数中漏掉或重复。

主要形态交付用J=2 Re(Er*·Es)及N_J=J/max_cube|J|。正实共同gamma会约掉，因此不需等待实验标定。
任意复gamma的相位不会被该归一化消除。I_total中平方散射项也不能通过最终除一个常数消除gamma的影响。
总强度与固定参考对比度必须注明“给定CR/CS约定下的模型单位”。

### 4.4 关于论文图3的可比量

不得混淆Re(E)、|E|、|E|²及干涉交叉项。纯相位变化可以改变Re(E)，不能改变|E|。
如果图3标签与当前量的相位行为有疑问，在对照图中并列记录Re/Im/abs，明确比较量；不为复刻条纹外观而把Re(E)悄悄标成|E|。
论文图3的归一化规则作为展示参考，不自动等于本轮物理量定义。

## 5. 每层计算和保存

Er,Es是同一观察平面、同一实验室偏振基中的复向量。

I_ref=Er*·Er
I_scat=Es*·Es
J=I_cross=2 Re(Er*·Es)
I_total=(Er+Es)*·(Er+Es)=I_ref+I_scat+J
C_local=(I_scat+J)/I_ref，参考光接近零处保存NaN/掩膜而不是加任意epsilon。
S_fixed=(I_scat+J)/I_ref0，I_ref0是三种粒径共享的参考强度尺度。

不得提前删除|Es|²。不得把J称为总强度，不得把S_fixed称为纯干涉交叉项。
允许保持现有schema的单位散射基；保存gamma后Es=gamma*Es_unit，可完整重建总场。无需为了字段名称复制大量等价数据。

每个cube保留：x,y,zeta；Er和Es_unit实虚部；I_ref,I_scat,J,I_total,C_local,S_fixed；有效掩膜；配置和源码哈希；球心、半径、直径；归一化尺度；gamma；模型约定。
原始强度和复场禁止逐层/逐粒径各自归一化。形态展示的N_J另算，绝不能覆盖原值。

## 7. 最小验收，不把任务变成研究项目

### A 数据硬检查（必须）

三粒径、Fe₃O₄、NA、波长、几何、坐标、shape、完成层数、共享尺度、同一gamma；哈希；逐层有限性；非负I_ref/I_scat/I_total；J可正可负；I_total恒等式；字段回算。

### B 模型内部检查（必须）

约定映射文档及直接矩阵/直接方位积分对照；Mie无粒子/无折射率反差极限；被动吸收号；参考场变号仅使J反号；临界波矢衰减而非增长。
直接与降维积分分别比较Er和Es的复振幅，不能用强参考场掩盖弱散射场误差。

### C 数值检查（必须）

复用已通过的角积分、径向、Mie阶数和轴向检查；公式若变化则重跑。
角积分加密512/256→1024/512；径向1601→3201；轴向2→1nm抽检。对各场分别使用相对L2及相对最大绝对误差，阈值默认1e-3；近零场使用明确的共同尺度与绝对误差，不能静默变更分母。
抽取至少3种粒径×5个zeta×轴上/离轴点。
主10nm网格坐标的直接值正确，不等于双线性中点插值必达0.1%。原双线性0.15%–0.22%失败继续留档为“显示插值检查”，不删失败；本轮图像可用原始像素/明确的显示插值，不要求它成为新增全局网格门槛。

### D 图件验收（必须）

三组均有九层xy、两向纵剖面、轴向CSV/曲线、分解图、真实3D静态图与可打开HTML；标题/单位/色标/归一化说明完整；30nm形态图可辨；共同色标与形态色标分开；不裁去不喜欢的峰谷；所有网页图片链接可打开。
实际打开或用浏览器检查HTML；XML结构检查不能替代三维渲染验收。

### E 本轮不需要的事项

W/m²/V/m实测标定，真实颗粒折射率测量，FDTD/BEM独立物理认证，追踪/反演准确率，实验拟合，参数大搜索。标为NOT_REQUIRED_FOR_THIS_TASK，不伪造PASSED。

## 8. 复用、重算与停止条件

1. 先解包和校验已有完整数据，不先排队重算。
2. 原始候选数据立即可用只读出图工具做图，源状态保持原样。
3. 只修正文档/增加展示、且数值公式不变：复用3个cube，重新出图即可。
4. gamma仅改变为一个正实常数：由现有复场基重组合成即可，归一化J形态不变；保存新的推导配置与派生关系。
5. 角度、Fresnel、Jones或相位公式变化：先小网格通过内部检查，再统一重算三个正式cube。不能只修一组。
6. A–D通过后结束本轮，交付“明确近似和归一化约定下的论文模型仿真”。不再因没有实验标定或全波认证循环执行。
7. 若B仍存在不可消除的约定歧义，交付已有候选图及两种约定差异报告，状态只保留该具体问题，不把与任务无关内容列为阻塞；不得假装严格复现已通过。
