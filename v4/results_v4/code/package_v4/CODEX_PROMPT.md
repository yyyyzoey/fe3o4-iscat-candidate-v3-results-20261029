# 发给 Codex 的直接执行指令

本轮不要继续扩大研究范围。阅读本包README_START_HERE.md及docs/EXECUTION_SPEC.md，按下列任务实际执行，而不是再给方案。

## 一、用户目的

仅采用论文的前向仿真方法与近似，将对象换为Fe₃O₄，模拟直径30/100/200 nm的贴壁单球，在各自球心参考的名义景深窗口内沿zeta密切片。逐层求参考场与散射场的复向量干涉，构建三维through-focus数据体，给出清楚的论文式图和数值结果。
不做噪声、相机、追踪、反演、悬浮高度扫描、布朗运动、磁驱动、多粒子；不要求新增全波近场模型或真实实验绝对标定。

## 三、必须做，但不得无限扩展的核查

1. 核查论文S1–S13和正文OPD的记号映射，尤其标准Mie角、返回光p/s基、S2的符号。用直接Jones矩阵/方位积分与简化公式交叉核查，不只比图像好看程度。不能把换一个S2名字当推导证明。
2. 保留当前超临界扇区的模型近似，核查分支、相位衰减、积分收敛即可；不把球—基底全波认证变为新任务。
3. 明确CR=1、CS=eta的归一化模型约定；eta=asin(min(NA/ns,1))/pi=0.5。原文只说CS包含eta，因此不要写成原文唯一确定了CS/CR。单位散射场合成时只乘一次eta。不需要用户补充实验标定。
4. 主要形态图使用纯干涉项J及J/max_cube|J|，保留正负；它对正实共同幅度系数不敏感，但不能漏掉相位，不能据此忽略总强度中的散射平方项。
5. 保留原来的测试失败记录。横向双线性中点重建的约0.2%误差单列为显示插值检查，不自动判定主网格值错误。其他角积分、径向、轴向、Mie检查复用或在公式改动后重跑。
