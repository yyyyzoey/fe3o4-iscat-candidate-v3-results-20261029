# 01 方法与参数说明

> 逐符号核对与原始论文差异留档见 `validation/model_conventions.md`；数值证据见 `validation/jones_chain_numbers.json`。
> 本文只做工程说明：**哪些量是输入、哪些是约定、哪些是未认证**。

## 1 物理场景

玻璃基底上表面附着单个 Fe₃O₄ 球，水样覆盖，油浸高 NA 物镜从玻璃侧收集后向散射光，与界面反射的参考光在像面干涉。输出是**像面 through-focus 响应** `F(x, y, zeta)`：`zeta` 是焦点相对颗粒的扫描位移，**不是**样品空间近场 z。`sample_space_near_field=false`，`absolute_calibration=false`。

## 4 前向模型链条（概要）

1. 瞳面变量 `u = n_i sinθ`，在 `[0, NA]` 上求积；`u > n_s` 的 256 个点属超临界扇区。
2. `kz_s = sqrt(n_s² - u²)`，分支取 `Im(kz_s) >= 0`；后向 Mie 角 `mu_back = -kz_s / n_s`（`θ=π ↔ mu=-1`）。
3. 均匀球 Mie：`S1(mu), S2(mu)`，阶数默认 8（加密到 18 变化为 0，见 `numerical_audit.json`）。
4. Fresnel：**返回光方向为样品→玻璃**，正入射振幅 `2·1.33/(1.33+1.52) = 0.9333333333`。
5. 返回光 p/s 基：`ŝ = (-sinφ, cosφ, 0)`，`p̂ = ŝ × k_in`；散射场按该基投影得到 `S1·t_s`、`S2·t_p`。
6. 候选链：`scat_strength = 0.5j·(S1·t_s - S2·t_p)`；参考链：`ref_strength = 0.5j·(r_p + r_s)`。
7. 像面方位项含 `J0`、`J2`；第一分量为 `+(1-cosθd)·J2·sin(2φd)`（旧实现为负号，已修正）。
8. 场 → 强度分解：`I_ref = |E_r|²`，`I_scat = |γ|²·U`，`I_cross = 2 Re(γ·Q)`，`Q = conj(E_r)·E_s,unit`，`I_total = |E_r + γE_s,unit|²`。

### 必须说明的差异

| 项目 | 印刷式（补充材料 v3） | 候选实现 | 状态 |
|---|---|---|---|
| S6 / S13 的 `S2` 项符号 | `i(S2 t_p + S1 t_s)` | `i(S1 t_s - S2 t_p)` | 已有标量代数 + 直接 3D 投影证据；**整条 S3 矩阵链仍 UNVERIFIED** |
| `J2 sin2φ` 方位符号 | `+` | `+`（旧代码为 `-`，已修正） | 直接 φ 数值积分一致，通过 |
| 收集效率 η | `C_S` 含 η | 生产 cube 不含 η（`CS=1`） | 约定差异，已标注 |
| γ | 文献未唯一定义 | `0.5+0i`，只乘一次 | 演示约定，非标定 |

`μ_back` 的取值使 `θ=π` 对应 `mu=-1`；若按印刷式逐字相加，后向散射恒满足 `S2(π) = -S1(π)` 且正入射 `t_p = t_s`，会把任何粒子的轴上后向散射场整体消掉（纯电偶极子极限给出 `|印刷式和| = 0`，`|链式差| = 3.0`）。这是候选实现偏离印刷式的**唯一**结构性理由，也是它仍只能算 CANDIDATE 的原因。

## 5 输出信号

| 数据集 | 含义 |
|---|---|
| `signals/E_ref_real, E_ref_imag` | 参考复场（相对共享尺度） |
| `signals/E_scat_unit_real, E_scat_unit_imag` | 不含 γ、不含 η 的散射复场 |
| `signals/I_ref` | `|E_ref|²` |
| `signals/I_scat` | `|γ|²·U` |
| `signals/I_cross` | `2 Re(γ·Q)`，**主信号 J，可正可负** |
| `signals/I_total` | `I_ref + I_scat + I_cross` |
| `signals/contrast_local` | `(I_scat + I_cross)/I_ref`，`I_ref ≤ 1e-12` 处为 NaN |
| `signals/contrast_fixed_reference` | `I_scat + I_cross`（固定参考归一化） |
| `masks/defined_contrast, stable_reference` | 对比度定义域与稳定参考掩码 |
| `coords/*` | `x_object_nm`、`y_object_nm`、`zeta_nm`、`oil_thickness_nm` |
| `attrs` | 配置 JSON、`config_sha256`、`implementation_sha256`、分类与状态 |
