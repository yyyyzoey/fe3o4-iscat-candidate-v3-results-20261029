# 05 复现说明

## 1 环境

- Python 3.11（`python -X utf8`），依赖见 `code/package_v4/requirements.txt`：`numpy`、`h5py`、`matplotlib`、`Pillow`、`pypdf`、`pypdfium2`、`scipy`。
- 环境快照：`provenance/environment.json`。
- 三个离线三维页面无需网络；审计时用 Microsoft Edge headless 并屏蔽 DNS 验证过。

## 2 一分钟自检（不读 1.3 GB 数据）

```powershell
python -m unittest discover -s code/solver/tests -p test_*.py -v
python -m unittest discover -s code/package_v4/tests -v
python code/package_v4/tools/audit_final_tree.py --results .
python code/package_v4/tools/verify_results_bundle.py --help
```

## 3 完整复算（需要三份 HDF5，位于 `data/D*/cube.h5`）

```powershell
# 1) 逐层流式复读三份 cube：坐标、复场、代数恒等式、masked NaN
python code/package_v4/tools/verify_results_bundle.py <full.zip> --mode full `
  --expect-sha256 <ZIP_SHA> --expect-bytes <BYTES> --expect-entries <N> --out verify.json

# 2) 存盘样本独立复算（需要冻结配置）
python code/solver/tools/spot_recompute_saved.py --cube data/D030nm/cube.h5 --out spot.json

# 3) 收敛与中点重建审计
python code/solver/tools/numerical_audit.py --config code/solver/configs/target_Fe3O4_NA145.json
```

## 4 重新出图与离线页面

```powershell
python code/figures/make_final_figs.py
python code/figures/make_montages.py
python code/figures/make_xdmf.py
python code/package_v4/tools/render_html_final.py --results .
```

图件只从 `data/D*/cube.h5` 读，不接受外部插值/放大输入。

## 5 复现的三条硬约束

1. **不得**用 pilot 或插值放大替代 171×241×241 主网格；主网格每个点都是直接求值。
2. **不得**降低 NA、缩小网格或改 `zeta` 范围来"通过"验收。
3. 若某物理假设无法证实，保持 `CANDIDATE/UNVERIFIED`，并保留可复现的阻塞证据（本树 `status.json.blockers`）。
