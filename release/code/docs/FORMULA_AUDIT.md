## B. 本次确认的具体问题

### P0-01：后向Mie角与返回p偏振基的混用风险

旧代码：`mu_back=-kzs/ns`，随后 `scat_strength ∝ S2*tp+S1*ts`。

标准Mie角函数在正后向 `mu=-1` 满足S2=-S1。因此当法向tp=ts时，旧组合强制相消。对只保留电偶极a1=1、b1=0的解析例子：S1=1.5，S2=-1.5；旧和为0，而将Mie e_theta投影到返回光p基后出现符号翻转。

独立几何检查：Mie原角从入射+Z量起。θ=π时 `e_theta=(-cosφ,-sinφ,0)`，它与沿返回光轴定义的横向p相反。因而候选采用 `S2_return=-S2_Mie`，仍使用标准的后向Mie角。当前 `src/iscat_core.py` 中使用 `S1*ts-S2*tp`。

**已证明的范围**：旧组合确实发生该相消；候选能通过电偶极的笛卡尔场基变换检查。**尚未证明的范围**：完整QWP/PBS及作者S6的全部约定已经逐式一致。必须审计整条Jones链，不能简单宣称论文错了，也不能把改号本身当作最终物理证明。

禁止通过将Mie角换成前向角来“修补”后向信号，除非能明确证明定义映射；前/后向对200 nm Mie球不是同一个物理响应。

### P0-02：角积分后Ex符号

补充S12/S13的第一分量是 `+(1-cosθd)J2(q)sin(2φd)`。旧 `fields_at_slice` 写为负号。

这是方位角积分的结果：瞳面中的 `-sin(2φ)` 与二阶Bessel Fourier积分中的 `i²=-1` 共同变成正号。本包采用不共享解析Bessel公式的直接φ积分验证这一点，并在候选改成正号。

因为旧代码同时给Er_x与Es_x改号，`|Er+Es|²`等一些标量可能不变，所以旧标量测试不能发现该问题；但输出的复矢量场与论文固定坐标约定不一致。

### P0-03：相对场幅与相位未被文献唯一确定

旧Cs/Cr=0.5是人为规范，不是标定。S6只说明Cs包含η，不能由此推出Cs/Cr=η，更不能确定所有漏掉的相对复相位。

本包输出单位散射基和复Q，使γ的影响可重新计算。默认γ0.5+0i仅保留演示的连续性。禁止将该值描述为Fe₃O₄的绝对对比度转换系数。

### P0-04：高NA延拓不是全波界面验证

旧代码确实积分到1.45，没有暗中截为1.33；但“有限数值、正确支、积分收敛”并不能证明超临界有限球角谱和界面耦合正确。均匀介质Mie远场加Fresnel延拓的适用范围必须说明。

当前仍保持该近似作为候选，必须单列未核实项。原文理论NA1.35也超过水1.33，不能说只在用户1.45下才出现。

### P1-05：原始对比度的弱参考光问题

参考PSF横向弱光区域可能使 `(Is+Ix)/Ir` 数值很大。旧代码保留数值但仅以显示掩膜处理。本包区分数学有效掩膜（Ir>1e-12）和稳定显示掩膜（Ir>=0.005），同时保存固定参考归一化结果。两个阈值是数值规则，不是物理遮挡。

不允许删除外环、给分母加随意常数、用逐图最大值归一化来隐藏问题。必须报告掩膜比例；任何结论若只使用掩膜内区域，需明确区域。

### P1-06：原版计算精度和写入验收

旧代码先把复场转float32再算强度，测试主要体现低精度内部恒等。候选保持complex128/float64计算、float32只用于磁盘；再从磁盘复读对照。新增输入/源码哈希、原子写入和续跑校验，避免半文件或混版本当结果。

### P1-07：原版材料硬编码阻止论文控制组

旧 optical_params 只接受material_name='Fe3O4'。候选允许控制材料参数，目标Fe₃O₄限制放在任务与配置测试里。控制组不是目标组，输出路径与元数据必须隔离。
